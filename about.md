## Hello world

I'm a developer in the northeast US. My background is primarily in FOSS Web Development (PHP, Python, Ruby, PostgreSQL, MariaDB, etc), but the vast majority of stuff I do nowadays is in Ruby and Ruby on Rails &#129409;. I'm a big advocate for using technology to reduce cognitive load (particularly in the cases where technology is already increasing it!), in the veins of Krug's "Don't Make Me Think" and similar work.

## This Site

This site will be technical-focused, and include discussion about software design, Rails, DevOps stuff, UX, intended for an informed, but not expert-level, audience.

As an experiment (and to finally force me to learn more of this whole JavaScript thing, as well as practice my DevOps), this site is statically built using <a href="https://bridgetownrb.com">Bridgetown.rb</a>, using <a href="https://tailwindcss.com">TailwindCSS</a> as its framework. It uses JavaScript, but in a state of protest.
